## Overview

Waystones helps organize the job-application process by combining application tracking with job-posting parsing and Google Sheets synchronization.

## My contribution

I developed and deployed the full-stack application using Supabase and Cloudflare. My work included Google OAuth authentication, job-posting parsing, Google Sheets API integration, server-side credential handling, and user-controlled data management.

## Problem

Keeping an application tracker up to date can involve repeatedly collecting job details and maintaining records across different tools. Waystones brings those tasks into a connected workflow.

## Approach

The application combines structured application records with tools for collecting and synchronizing information. Google sign-in handles authentication, while the Sheets integration supports keeping application data available across platforms.

## Implementation

- Supabase for application data storage.
- Cloudflare for deployment.
- Google OAuth for authentication.
- Job-posting parsing to support application data collection.
- Google Sheets API synchronization.
- Server-side credential handling and user-controlled data management.

## Current state

Waystones has been developed and deployed. The core application connects job-data collection, organization, and synchronization in one workflow.
