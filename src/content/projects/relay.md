## Overview

Relay brings the details of an automotive build into one place. It combines project planning and documentation with features for sharing and discovering builds.

## My contribution

I developed and deployed the database-backed application using Supabase and Cloudflare. I built features for managing parts, costs, timelines, objectives, and build documentation, and integrated third-party services alongside sharing and discovery features.

## Problem

An automotive project involves more than a list of parts. Costs, objectives, timelines, and documentation all need to stay connected as a build develops. Relay provides a place to organize those details together.

## Approach

The platform centers on the build itself: what it needs, what it costs, what it aims to achieve, and how it progresses. Sharing and discovery extend that experience beyond an individual project.

## Implementation

- Database-backed storage using Supabase.
- Deployment using Cloudflare.
- Management of parts, costs, timelines, and objectives.
- Build documentation.
- Third-party integrations and project sharing/discovery features.
