## Problem

Small interaction ideas can get lost between sketches and finished projects. A dedicated playground gives each idea somewhere to develop without requiring a complete application.

## Approach

Start with one interaction, build a small prototype, and test it on a phone as well as a desktop. Keep the surrounding interface quiet so the idea remains the focus.

- Choose a single question to explore.
- Build the smallest useful version.
- Record what worked and what needs another pass.

## Implementation

Each experiment can remain independent. Introduce browser JavaScript only when an interaction needs it, and document the decisions alongside the result.

```ts
const experiment = {
  question: 'Can this interaction be easier to understand?',
  stage: 'prototype',
};
```
